## 2. Срочно — ошибки, которые действуют на машине владельца сейчас

Переписывание займёт поставки 3–8. Эти дефекты дают агенту обойти защиту или ломают работу уже сейчас, поэтому
предлагаются точечными исправлениями на master до продолжения переписывания (нужно согласие владельца):

1. Подмена проверки политики: хук `python -m artel.policy` запускается с cwd = рабочее пространство агента;
   файл `artel/policy.py` в нём подменяет проверку (claude_code.py:157-160). Исправление: запуск по абсолютному пути
   скрипта, как у прокси MCP.
2. Секреты в окружении агентов: оболочки наследуют весь `os.environ`, включая `ARTEL_TELEGRAM_TOKEN` и ключи API
   (builtin_tools.py:78, claude_code.py:123, codex.py:94). Исправление: белый список переменных.
3. Проверки задач (`checks`) выполняются без политики, Guardian и песочницы, с полным окружением (manager.py:337).
4. Журнал событий без маскировки секретов уходит в git-ветку `evolve/journal` (kernel.py:51, engine.py:283).
5. Подпроцессы: `stderr` не вычитывается — зависание при >64 КБ (claude_code.py:262, codex.py:291);
   `terminate_tree` не убивает группу процессов — сироты и бесконечное чтение (tools.py:115).
6. `tokens_total=0` у Codex: расход читается только из `turn.completed`, который не приходит, потому что процесс
   убивается раньше (codex.py:313-352). Без этого U3 в приёмке неизмерим.
7. Гонка записи `project.json` — причина красного CI на Windows (project.py:244-254); потерянное пробуждение в
   индексации эмбеддингов — причина падения на macOS «< 10 с» (embeddings.py:281-329).

## 5. Язык

Остаёмся на Python. Узкое место — ожидание модели, а не код; найденные дефекты логические, Rust их не исключает;
модели правят Python надёжнее, что важно для самоулучшения. Зависимостей 3 прямых / 20 с транзитивными, и их можно
свести к 0–1 (прямой HTTP вместо SDK в П4, TOML из стандартной библиотеки вместо YAML) — Rust-аналог тянет 100–200
крейтов. Низкоуровневый язык оправдан только для изолированного адаптера песочницы (ToolPort) после П3, если
понадобится.
