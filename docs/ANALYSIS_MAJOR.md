# Разбор ведущих coding-харнессов: что взять в Artel

Разобраны по исходникам (клоны `--depth 1`, октябрь 2026). У каждого пункта — путь к коду, откуда идея.

## OpenCode (`anomalyco/opencode`, MIT)

| Механизм | Где | Суть |
|---|---|---|
| Теневые git-снимки + откат | `packages/opencode/src/snapshot/index.ts`, `session/revert.ts` | Отдельное git-хранилище на каждый шаг; объекты и индекс переиспользуются из основного репо (alternates), поэтому быстро даже на огромных репо |
| Сжатие контекста | `session/compaction.ts` | Сначала стирается вывод старых инструментов (старше 2 пользовательских ходов, кроме защищённых), затем суммаризация; плагины могут подменить промпт сжатия |
| Нечёткое применение правок | `tool/edit.ts` | Поиск блока по якорям с расстоянием Левенштейна (приёмы Cline и Gemini CLI `editCorrector`) |
| Диагностика LSP после правки | `tool/edit.ts`, `tool/write.ts`, `lsp/` | Ошибки компилятора и линтера возвращаются агенту в том же ходе |
| Длинный вывод → файл | `tool/truncate.ts` | Вместо обрезки: полный текст в файл (хранится 7 дней), агенту — превью и путь |
| Режимы plan / build | `session/reminders.ts`, `tool/plan.ts` | Синтетические напоминания при переключении режима |
| Code-mode | `tool/code-mode.ts` | Модель пишет программу, вызывающую инструменты и MCP |
| Права по шаблонам | `permission/evaluate.ts`, `permission/arity.ts` | allow / ask / deny по шаблону, учёт аргументов bash |

## Codex (`openai/codex`, Apache-2.0)

| Механизм | Где | Суть |
|---|---|---|
| Guardian | `codex-rs/core/src/guardian/`, `prompts/templates/guardian/` | Асинхронный ревьюер риска траектории и согласия пользователя; высокий риск включает блокирующую проверку следующих действий. Доверенные источники — только пользователь, разработчик и AGENTS.md |
| execpolicy | `codex-rs/execpolicy/` | Правила на Starlark: `prefix_rule(pattern, decision=allow/prompt/forbidden, justification, match, not_match)`; примеры проверяются при загрузке (юнит-тесты политики) |
| Песочница | `codex-rs/linux-sandbox/` | bubblewrap, сетевой прокси с политиками |
| Двухфазная память | `codex-rs/memories/` | Фаза 1: из каждого прогона — структурированная память, вычистка секретов, задания под арендой с backoff; фаза 2: агент консолидации |
| Бюджет на дерево агентов | `core/src/rollout_budget.rs` | Общий учёт и напоминания на порогах для всех субагентов |
| Канонизация команд | `core/src/command_canonicalization.rs` | Одобрение команды стабильно между `/bin/bash -lc` и `bash -lc` |

## Qwen Code (`QwenLM/qwen-code`, Apache-2.0, форк Gemini CLI)

| Механизм | Где | Суть |
|---|---|---|

| Микросжатие | `services/microcompaction/` | Старые результаты и медиа заменяются заглушками |
| История файлов, откат | `services/fileHistoryService.ts`, `branch-points.ts` | Снимки по ходам; неудачная копия не выдаётся за текущую |
| Среды исполнения | `services/container-execution-*`, `ssh-execution-*`, `gitWorktreeService.ts`, `cronScheduler.ts` | Контейнер, SSH, worktree, задачи по расписанию |
